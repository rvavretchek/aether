O que ficou fechado para o MVP

  • tRPC + Prisma + TypeScript-first, decisões decisivas, sem "ambos suportados"
  • Auth: JWT + Refresh Token, Argon2id + Pepper
  • CLI enxuto, testes com scaffolding automático, admin funcional sem drag-and-drop
  • Quatro preparações de arquitetura sem custo de escopo: multitenancy no schema, modelo de entidades hierárquico, AuthProvider como adapter, abstração de secrets

O que fica no horizonte, com nome

  • Auth pluggável: Keycloak, OpenBAO, e o que a comunidade trouxer depois
  • Painel admin estilo NDS: árvore completa, drag-and-drop, objetos de negócio reais
  • Criptografia seletiva com custódia múltipla de chaves, multitenant de verdade
