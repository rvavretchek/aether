## Discrepancies summary (flagged items only)

1. **HIGH — ESLint 9.x is EOL as of 2026-08-06**, nine days before the spine's own `updated: '2026-08-15'`. ESLint 10 has been stable since February 2026 (10.8.0 since July). No deferral rationale is given (unlike the TS-7 and React-Router-v8 entries), which is the strongest signal in this review that the ESLint line item was asserted rather than checked against the web.
2. **MEDIUM — pnpm pinned at 10.x with no rationale**, while pnpm 11.0 GA'd 2026-04-28 (~4 months before the spine's date) and is now at 11.11+. Contrast with how the spine explicitly justifies staying behind on TS 7 and React Router v8 — pnpm gets no such treatment, suggesting it wasn't re-checked.
3. **MEDIUM — Vite pinned at 7.x with no rationale**, while Vite 8.0 GA'd 2026-03-12 (~5 months before the spine's date) and is the current major (8.2.1). Same asymmetry as pnpm: no acknowledgment that a newer major exists, unlike the TS-7/RR-8 pattern. Vitest's "3.x aligned to Vite 7" pin inherits this same gap.
4. **MEDIUM — Prisma multi-database claim (AD-5/AD-11) is technically still true but glosses over mandatory driver-adapter wiring** introduced as part of Prisma 7's Rust-engine removal (one adapter package per target DB — Postgres/MySQL/MS-SQL — now required, not optional). AD-5's "Prisma Client estendido... construído por request" doesn't mention this adapter-instantiation step, which is a real v7-specific mechanic worth a line in the architecture.
5. **LOW — TS 7.0's cited GA date (2026-08-05) is off by about a month** (actual GA was 2026-07-08). The reasoning for staying on TS 5.9 (ecosystem/tooling not yet on 7.0 — no stable programmatic API, typescript-eslint/Vue/Svelte/Astro/Angular can't consume it) is independently verified as still correct; only the specific date is wrong.

## Positive findings (landmines checked and cleared)

- tRPC 11.x's Fastify adapter genuinely requires Fastify v5+ (v4 silently breaks responses) — spine's Fastify 5.x pick is the correct, load-bearing choice, not a coincidence.
- React Router ^7 in data-router/client mode is confirmed usable without SSR, with React 19 as a supported dependency — no landmine.
- Prisma Client Extensions (AD-5's actual mechanism) are confirmed to survive the Prisma 7 jump and are Prisma's documented replacement for the removed `$use` middleware — AD-5's foundation holds.
- OWASP Argon2id baseline (m=19456, t=2, p=1) matches current guidance exactly.
- Node 24, TypeScript 5.9 (as last 5.x), tRPC 11.13.x, Prisma 7.x, Zod 4.4.x, React 19.x, Prettier 3.x, argon2, jose, and Pino are all current, existing, actively maintained choices with no drift detected.
